Blind listening

Each block is one line, read by several voices. Clip labels are random, and the clips in each block are in a shuffled order.

For every clip, rate natural: how much it sounds like a person speaking (1 not at all, 5 completely), and feeling: how well it carries the line's intended feeling (1 not at all, 5 exactly). Then pick your favourite clip for the line.

Ratings are kept in this browser between sittings. When every clip is rated, export and save the file as ratings.csv in the folder that holds this page.
